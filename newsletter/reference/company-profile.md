## 2. 서비스 범위 (행사 전 · 중 · 후)

| 단계 | 기능 |
|---|---|
| **행사 전** | 초청장 페이지, 온라인 초청장 발송(참가업체별 발송량·경로 추적, 국/영문), 카카오톡 초대장(바이럴), 이메일 사전등록 안내, 참관객 MY QR 사전 발송(알림톡/문자/외국인 이메일), **티켓링크·네이버예약 API 연동**(구매 즉시 MY QR) |
| **행사 중** | 유인 등록대(POS), 셀프등록 키오스크(결제·출입증 출력), **AI 안면인식 무인등록**, 모바일 현장등록(국/영문), 출입증 제작(종이 출입증·친환경), 출입통제·세션관리·체류인원 확인, 참가업체용 고객관리시스템(바이어 스캔, 3가지 타입), 스폰서 광고 노출(모바일·키오스크·출입증·배너), **실시간 모니터링 대시보드**(govent Cloud) |
| **이벤트 부가** | 참관객 동선·관심기업 추천(알림톡 → 쇼가이드 페이지), 모바일 스탬프 투어, 룰렛 경품 |
| **행사 후** | 데이터 결과보고(참관객 현황·카테고리·지역/국가, 초청장 반응, 교차분석, 동선 분석, 방문 추적), 감사메일·참관 후기 설문 |

### 보유 장비 (상시 구매 가능 수량 기준)
키오스크 41 / POS 30 / 노트북 35(+렌탈 100) / 패드형 모니터 40 / 출입증 프린터 80 / 2D 스캐너 핸디형 600·탁상형 100

### 기술·운영
- AWS 기반 웹/DB 서버 이중화, 방화벽
- 장애 등급(1~3급)과 복구 목표 시간, 현장 인터넷 장애 시 로컬 저장 후 동기화
- 서버 자동 풀백업(매일) + 로컬 백업

## 3. 경쟁사 비교용 기능 체크리스트
섹션 4에서 동종 업체 소식을 다룰 때 이 표의 칸에 대어 보고 **"우리 있음 / 우리 없음 / 우리가 앞섬"**을 판단한다.

| 영역 | 우리 현황 | 경쟁사 소식에서 볼 포인트 |
|---|---|---|
| 사전등록·초청장 | ✅ 국/영문, 카카오 초대장, 경로 추적 | 다국어 확장(중·일), 셀프 빌더(주최사가 직접 페이지 제작) |
| 티켓 판매 | ✅ 티켓링크·네이버예약 연동 | 자체 결제/PG, 다이나믹 프라이싱, 해외 결제 |
| 현장 등록 | ✅ 유인·키오스크·모바일 | 대기열 관리, 모바일 월렛(애플/구글 월렛) 출입증 |
| 생체인증 | ✅ AI 안면인식 (NHN Cloud 협약) | 안면인식 입장 확산 여부, 개인정보 규제 이슈 |
| 출입통제·세션 | ✅ QR 리더 + PC, 체류인원 | RFID/NFC·비콘 기반 자동 체크인, 게이트형 장비 |
| 참가업체 리드 수집 | ✅ 고객관리시스템(바이어 스캔) | 앱 기반 리드 스캔, CRM 연동 |
| 매칭·네트워킹 | △ 관심기업 추천 | AI 비즈매칭, 미팅 예약, 참관객 앱 |
| 데이터·리포트 | ✅ 실시간 대시보드, 결과보고 | 셀프서비스 BI, 행사 간 벤치마크, AI 인사이트 요약 |
| 참여 이벤트 | ✅ 스탬프 투어, 룰렛 | 게이미피케이션 플랫폼화 |
| 지속가능성 | ✅ 종이 출입증(비닐 Zero) | 디지털 배지, 탄소 배출 리포트 |
| 해외 | △ 국/영문 지원, 해외 참가업체 대응 | 해외 행사 수행, 글로벌 플랫폼의 국내 진출 |

> ✅ = 소개서에 명시됨, △ = 일부만 있거나 범위가 제한적. 판단은 소개서 기준이므로 실제 현황은 사내 확인 후 고친다.

## 4. 뉴스레터에 반영한 점
- **venue 관계**: 코엑스(연간 계약)·세텍·벡스코·울산전시컨벤션센터(UECO)가 지정협력 venue → 세텍과 UECO를 캘린더 **1순위로 승격**
- **티켓 플랫폼 = 파트너이자 잠재 경쟁자**: 티켓링크·네이버예약은 연동 파트너이므로 "경쟁"이 아니라 **"파트너 동향"**으로 다룬다
- **NHN Cloud 등 기술 파트너**도 별도 분류로 모니터링 (안면인식·클라우드)
- **섹션 2·3의 ⭐(자사 수행) 표시**에 실적 리스트를 활용

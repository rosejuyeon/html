# 스태프 페이지 생성기

행사 스태프 매뉴얼·공지 페이지를 폼만 채워서 만드는 도구입니다. 코드를 몰라도 쓸 수 있고, 서버 없이 브라우저에서만 동작합니다.

- 주소: https://rosejuyeon.github.io/staff-page-builder/ (GitHub Pages를 켠 뒤)
- 기준 템플릿: `rosejuyeon/html` 저장소 `kimst-2026` 브랜치의 `staff.html`

## 사용법

1. 생성기를 열면 kimst-2026 스태프 페이지가 예시로 채워져 있습니다. 예시를 고쳐 씁니다. 미리보기에 바로 반영됩니다.
2. 섹션과 블록(단계 카드, 경고 박스, 금액표, 태그 목록, O/X 대상 목록, 행사일정표, 링크 버튼, 자유 텍스트)을 추가·삭제하고 순서를 바꿀 수 있습니다.
3. 강조 표시: `==형광펜==`, `**굵게**`, `((회색 보조 문구))`, `[링크 글자](주소)`
4. **HTML 다운로드**로 파일을 받습니다.
5. `rosejuyeon/html` 저장소에서 행사 브랜치를 고르고 **Add file → Upload files**로 올립니다.
   새 행사라면 `kimst-2026` 브랜치를 고른 상태에서 브랜치 버튼에 새 이름을 입력해 브랜치를 만듭니다.
6. `https://raw.githack.com/rosejuyeon/html/<브랜치>/<파일>.html` 링크로 공유합니다.

작성 내용은 브라우저에 자동 저장됩니다. 다른 팀원에게 넘기거나 다음 행사에 재사용할 때는 **설정 내보내기 / 설정 불러오기**를 씁니다.

사용법
  1. 내용 고치기 — 처음에는 한국군사과학기술학회 학술대회 스태프 페이지가 예시로 들어 있습니다. 예시를 고쳐 쓰면 오른쪽(휴대폰에서는 아래쪽) 미리보기에 바로 반영됩니다.
    • 섹션은 ↑ ↓로 순서를 바꾸고 ✕로 삭제합니다. 섹션 안에는 여러 블록(단계 카드, 경고 박스 등)을 넣을 수 있습니다.
    • 상단 바로가기 메뉴는 섹션 제목으로 자동으로 만들어집니다.
  2. 강조 표시 — 글을 쓰는 칸에서 아래처럼 쓰면 됩니다. 줄을 바꾸면 페이지에서도 줄이 바뀝니다.
    • ==스테이플러로 함께 찍기== → 형광펜
    • **수령처에서 교환** → 굵게
    • ((강은호 前방위사업청장)) → 회색 보조 문구
    • [중식쿠폰 안내](#lunch) → 링크. 괄호 안에 웹 주소나 #섹션주소를 씁니다.
  3. 파일 받기 — 위의 HTML 다운로드를 누릅니다. 파일 이름은 아래 ‘공유 링크’ 칸에서 정합니다.
  4. 새 행사라면 브랜치 만들기 — github.com/rosejuyeon/html에 들어가 왼쪽 위 브랜치 버튼(main 등)을 누르고 kimst-2026을 먼저 고릅니다. 다시 브랜치 버튼을 눌러 새 이름(예: amxpo-2027)을 입력하고 Create branch … from kimst-2026을 누릅니다. 행사마다 브랜치를 따로 쓰고, 서로 합치지 않습니다.
  5. 파일 올리기 — 같은 화면에서 행사 브랜치가 선택된 것을 확인하고 Add file → Upload files를 누릅니다. 다운로드한 파일을 끌어다 놓고 Commit changes를 누릅니다. 같은 이름의 파일이 있으면 새 파일로 바뀝니다.
  6. 공유하기 — 아래 ‘공유 링크’에 나온 주소를 팀에 보냅니다. 올린 직후에는 반영까지 몇 분 걸릴 수 있습니다.
  7. 작업 저장 — 작성 내용은 이 브라우저에 자동 저장됩니다. 다른 팀원에게 넘기거나 다음 행사에 다시 쓰려면 설정 내보내기로 받은 파일을 전달하고, 받은 사람은 설정 불러오기로 엽니다.
